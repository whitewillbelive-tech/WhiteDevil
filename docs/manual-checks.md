# Windows 사용자 검수

자동 검증은 격리된 Linux Chromium에서 수행합니다. 아래 항목은 Windows PC의 실제 Chrome·Edge와 사용자의 작업 방식으로 최종 확인해야 합니다. 이 문서의 목록은 수동 검수 완료를 뜻하지 않습니다.

- [ ] Chrome·Edge에서 긴 한국어 문장, 줄바꿈, IME 조합 입력이 자연스럽고 클릭·탭 전환 후 보존된다.
- [ ] 많은 인물·사건을 입력했을 때 검색과 시즌 비교표의 밀도가 적절하다.
- [ ] 마우스·트랙패드로 전개도 이동·크기 변경·확대·화면 이동을 편하게 사용할 수 있다.
- [ ] Windows 파일 선택기에서 JSON 다운로드·파일명·가져오기가 동작한다.
- [ ] 실제로 내려받은 JSON을 별도 브라우저 프로필에서 복원하고 인물·사건·전개도를 확인한다.
- [ ] 브라우저 프로필과 서버 주소를 바꿨을 때 저장 위치가 달라짐을 이해하고 백업을 옮길 수 있다.
- [ ] 실제 데이터로 한 번에 긴 편집을 하기 전, 소량 입력·새로고침·JSON 백업·복원을 확인한다.
- [ ] 좁은 창, 브라우저 확대, 키보드 탐색, 읽기 도구에서 주요 편집이 가능하다.
- [ ] 장기 저장을 위해 브라우저 데이터 삭제 정책과 별도 JSON 백업 주기를 정한다.

추후 개선 후보는 사용자 자료에 맞춘 대량 탐색 성능, 변경 이력의 영구 보관, 원고 출처 연결, 명시적인 권한과 충돌 처리를 갖춘 사용자 관리 저장소입니다. 원고나 설정 자료 이관은 실제 자료가 제공된 후 별도 검증 단계로 진행합니다.
